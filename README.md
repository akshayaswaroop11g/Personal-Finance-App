# FinTrack - Personal Finance Manager

A personal finance management app that tracks income, spending, and savings with automatic budget reports.

## Features

- **Dashboard** - Overview of income, expenses, savings, and balance with interactive charts
- **Transaction Management** - Add, edit, delete, filter, and search transactions
- **Budget Tracking** - Set monthly budgets per category with progress indicators
- **Automatic Reports** - Generate detailed monthly reports with breakdowns, charts, and budget performance
- **Data Persistence** - All data stored in browser localStorage
- **Sample Data** - Starts with a clean, empty dataset so users can enter and analyze their own financial data

## Getting Started

Open `index.html` in any modern web browser. No build step or server required.

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla)
- Chart.js for data visualization
- localStorage for data persistence
